Customer Retention & Booking Follow-Up Agent

An AI assistant that notices when a regular customer goes quiet, matches the latest sailings from the Heung-A website, and drafts the follow-up email. A salesperson always reviews and sends. Asisten AI yang mendeteksi pelanggan rutin yang mendadak diam, mencocokkan jadwal kapal terbaru dari web Heung-A, lalu menyiapkan draft email follow-up. Sales selalu mereview dan mengirim sendiri.

How it works, start to finishCara kerja, dari awal sampai akhir

Seven steps, repeated every week. Steps 1–4 run locally for free; Claude writes the emails inside your session.Tujuh langkah, diulang tiap minggu. Langkah 1–4 berjalan lokal dan gratis; Claude menulis email di dalam sesi Anda.

1

Import CRM dataImpor data CRM

Reads the Excel booking export: customer, route, ETD, TEU, sales.Membaca ekspor booking Excel: customer, rute, ETD, TEU, sales.

2

Get live scheduleAmbil jadwal terbaru

Reads sailings and terminals from the public Heung-A schedule page.Membaca sailing dan terminal dari halaman jadwal publik Heung-A.

3

Find quiet accountsCari akun yang diam

Regular customers with no sailing for 14+ days (weekly) or usual gap + 14 days (monthly).Pelanggan rutin tanpa sailing 14+ hari (mingguan) atau jeda biasa + 14 hari (bulanan).

4

Rank by priorityUrutkan prioritas

Vietnam route +50, average TEU × 3, days quiet (max 60).Rute Vietnam +50, rata-rata TEU × 3, lama diam (maks. 60).

5

Draft the emailTulis draft email

Friendly, short, two real sailings, no invented numbers. English by default, signed Sales Team Heunga Line.Ramah, singkat, dua sailing nyata, tanpa angka karangan. Default bahasa Inggris, tanda tangan Sales Team Heunga Line.

6

Review and sendReview dan kirim

Drafts open in Outlook as editable .eml files. A person presses Send.Draft terbuka di Outlook sebagai file .eml yang bisa diedit. Orangnya yang menekan Send.

7

Track the replyLacak balasan

Each customer has a status: sent, replied, reminder due, reactivated.Tiap customer punya status: terkirim, membalas, pengingat jatuh tempo, kembali booking.

↻

Repeat weeklyUlangi tiap minggu

Refresh the CRM export and the schedule first, so drafts use current data.Segarkan ekspor CRM dan jadwal dulu, supaya draft memakai data terbaru.

What is insideIsi project

Quiet-customer detectionDeteksi akun diam

Weekly and monthly patterns, priority score, internal accounts excluded, filter by salesperson.Pola mingguan dan bulanan, skor prioritas, akun internal dikecualikan, filter per sales.

Live schedule from the webJadwal langsung dari web

Fetched through the browser with departure and arrival terminals. Space is not on the public site, so emails say it is confirmed at booking.Diambil lewat browser lengkap dengan terminal muat dan tujuan. Space tidak ada di web publik, jadi email menulis space dikonfirmasi saat booking.

Outlook-ready draftsDraft siap Outlook

.eml drafts, English or Indonesian, with optional attachments and a warning if the schedule file is older than 12 hours.Draft .eml, Inggris atau Indonesia, lampiran opsional, dan peringatan bila file jadwal lebih tua dari 12 jam.

Customer schedule pageHalaman jadwal customer

Branded HTML page (EN with ID button) plus PDF for all routes and per route, as a backup if a mail gateway blocks .html.Halaman HTML berlogo (EN dengan tombol ID) plus PDF semua rute dan per rute, cadangan bila gateway email memblokir .html.

Follow-up trackingPelacakan follow-up

A status file per customer drives reminders, meeting invitations, phone calls and reactivation.File status per customer menggerakkan pengingat, ajakan meeting, telepon, dan deteksi kembali booking.

Safe by designAman sejak awal

Never sends email. Real sailings only. Customer data and outputs are git-ignored.Tidak pernah mengirim email. Hanya sailing nyata. Data customer dan hasil tidak masuk git.

How to run itCara menjalankan

Open Claude Code in the project folder and type the skill name. Add context such as the date, the new CRM export, or the language.Buka Claude Code di folder project, lalu ketik nama skill. Tambahkan konteks seperti tanggal, ekspor CRM baru, atau bahasa.

# in Claude Code / di Claude Code
/retention-followup today's date, new CRM export is in Downloads

# engine commands (run from retention_agent/) / perintah mesin
python agent.py import-crm data/crm_export.csv
python agent.py import-schedule data/schedule_raw.json
python agent.py report --today 2026-10-13 --schedule data/vessel_schedule_live.csv
python agent.py schedule-page --pdf
python agent.py save drafts.json --attach output/customer_schedule/Heung-A_Jakarta_Schedule.html
python agent.py due --today 2026-10-20 --schedule data/vessel_schedule_live.csv
python agent.py mark "<customer>" sent
CommandPerintahWhat it doesFungsinya
import-crmTurns the CRM Excel export (converted by convert_xls.ps1) into booking history.Mengubah ekspor Excel CRM (dikonversi convert_xls.ps1) menjadi riwayat booking.
import-scheduleTurns the raw Heung-A schedule data into the live schedule CSV.Mengubah data jadwal mentah Heung-A menjadi CSV jadwal terbaru.
reportFinds quiet customers, ranks them, matches two sailings each.Mencari akun diam, mengurutkan, dan mencocokkan dua sailing tiap akun.
saveSaves email drafts as .eml files (optional --attach).Menyimpan draft email sebagai file .eml (opsi --attach).
dueLists reminders and meeting invitations that are due.Menampilkan pengingat dan ajakan meeting yang jatuh tempo.
markRecords sent, replied, booked or closed.Mencatat sent, replied, booked, atau closed.
schedule-pageBuilds the customer schedule page and PDF backups.Membuat halaman jadwal customer dan PDF cadangan.
Refresh before you send. The schedule page cannot update itself from the Heung-A site, so fetch the latest schedule and rebuild the page right before sending. The page shows its update time and warns when it is two days old.Segarkan sebelum mengirim. Halaman jadwal tidak bisa memperbarui diri dari situs Heung-A, jadi ambil jadwal terbaru dan bangun ulang tepat sebelum mengirim. Halaman menampilkan waktu pembaruan dan memberi peringatan bila sudah dua hari.

Benefit and costManfaat dan biaya

Planning estimates from the Team 1 project card. Replace with measured numbers after the pilot.Estimasi perencanaan dari Kartu Proyek Tim 1. Ganti dengan angka terukur setelah pilot.

BenefitManfaat

120 follow-ups × (25 − 5) min ÷ 60 = 40 hours a month, about Rp 4.0 million at Rp 100,000 per hour. Plus speed (found every Monday) and quality (latest sailings in every email).120 follow-up × (25 − 5) menit ÷ 60 = 40 jam per bulan, sekitar Rp 4,0 juta pada Rp 100.000 per jam. Ditambah kecepatan (ditemukan tiap Senin) dan kualitas (jadwal terbaru di tiap email).

CostBiaya

Rp 5.0 million once to build, about Rp 1.0 million a month to run. This build uses the existing Claude subscription, so the real monthly cost may be lower.Rp 5,0 juta sekali untuk membangun, sekitar Rp 1,0 juta per bulan untuk menjalankan. Build ini memakai langganan Claude yang ada, jadi biaya bulanan sebenarnya bisa lebih rendah.

PaybackBalik modal

Net gain Rp 3.0 million a month, so 1.7 months. With only half of the savings it is still 5 months. Rule: build if payback is under 6 months.Keuntungan bersih Rp 3,0 juta per bulan, jadi 1,7 bulan. Dengan separuh penghematan pun masih 5 bulan. Aturan: bangun bila payback di bawah 6 bulan.
